Why this builds trust

Small Leaps sell by being useful. Four rules keep them that way.

Real value, no gate

No email wall. A visitor gets a complete plan for free, and leaves better off even if they never call.

Honest about limits

Every plan ends with “Where it gets complex”. Saying where DIY stops is what makes the expert credible.

A named expert

Each toolkit is written by, and hands off to, a real person: Dallas, Scott, Shemmah, Kristina or Erica.

Small leaps make the Big Leap easier

The visitor brings their plan to the call. The gaps they couldn't close become the proposal, and work they already did, and that holds up, is credited against the scope.

What makes this measurable

A handful of KPIs per phase, with example targets to start from and the simplest way to see each one. Set baselines in the first month, then tighten the targets.

Turn measurement on in three steps

  1. Add the Tag Manager ID. Put the Google Tag Manager container ID in GTM_ID at the top of tools/site_header.py (and the HubSpot Hub ID in HUBSPOT_ID), then run it. Every toolkit, widget and page starts sending the events listed here. Once the hub moves onto bigleap.com, its existing Tag Manager and cookie banner take over.
  2. Add two tags in Tag Manager. Add one GA4 configuration tag, plus one GA4 event tag that fires on any custom event starting with diy_ and passes toolkit, service and label. Mark diy_cta_click and diy_plan_copy as key events.
  3. Save one HubSpot report. Contacts and deals where the original source campaign is diy-toolkits, broken down by lifecycle stage and by utm_campaign (the toolkit). Give each owner a HubSpot meetings link so the source carries into the booking.

What gets tracked

Every toolkit, widget and page already sends engagement events (views, first answers, plans copied, Talk-to clicks and more) to the page's dataLayer. No personal data is sent.
